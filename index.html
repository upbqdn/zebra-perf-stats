What is left out — and why

332 unique blocks excluded. Counts below overlap. We select the first submission per node and hash before filtering; retries never replace a failed or catch-up first attempt.

  • 211 Catch-up blocks
  • 14 First large block after restart
  • 0 Not accepted by all three (including missing)
  • 203 Dispatch skew >25 ms
  • 320 Other host workload (including ±30 s padding)

A block is excluded for load when its first dispatch falls in any recorded non-experiment workload interval, from start through end, with a 30-second margin on both sides. The timeline includes overlapping intervals merged together. Ongoing runs count through the interval-export time. This excludes recorded background jobs, not all possible operating-system activity.

First large block after each Zebra restart

The first recorded block over 300 kB after each Starting zebrad marker is shown separately. It can pay a one-time ≈0.8 s verifying-key build, addressed by Zebra PR #12008. This is a timing-based proxy, not a direct measurement of key construction. Catch-up attempts also consume this first-large slot. A restart followed only by small blocks has no row.

Read these results in context

  • Isolated nodes have empty mempools: this does not measure public-network propagation, mining, transaction admission, or busy-mempool performance.
  • Zakura uses pruned storage; the two Zebra nodes use archive storage. Storage work and cache behavior differ.
  • All three run on one 16-core host, sharing CPU, memory and disks. Background activity, compaction and scheduling can affect the RPC round trip.
  • Restarts affect caches and initialization beyond the first large block. Only recorded submissions and startup timestamps are observable; earlier warm-up activity can make the first-recorded-large proxy conservative.
  • This is a descriptive snapshot, not a causal benchmark or a universal ranking. Size is not transaction composition, and adjacent blocks can be correlated.

Presentation inspired by Sovright's node comparisons; measurements and exclusions here come from our own records. No raw block payloads, RPC credentials or host telemetry are embedded.
